# Cocó Alerta

Protótipo experimental de monitoramento ambiental para a disciplina F054 — Fundamentos de Internet das Coisas. O sistema simula uma estação com ESP32, sensores, MQTT, Node-RED e um painel de classificação de risco para o Parque Estadual do Cocó.

Não é um detector certificado de incêndio e não há instalação real no parque.

O código, o circuito do Wokwi, o fluxo do Node-RED e o modo de executar estão em [`coco-alerta/README.md`](coco-alerta/README.md).
